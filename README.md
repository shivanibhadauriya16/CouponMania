# 🎟️ CouponMania

> A web-based coupon and cashback platform for discovering online shopping deals, discount coupons, and cashback offers.

## 📌 About the Project

CouponMania is a web project designed to help users discover online shopping deals, discount coupons, and cashback offers in one place.

The project is organized into separate frontend and backend components and focuses on providing a simple and user-friendly shopping-deal discovery experience.

## ✨ Features

- 🎟️ Browse discount coupons
- 💰 Discover cashback offers
- 🛍️ Explore shopping deals
- 📂 Discover offers across categories
- 🔗 Organized frontend and backend structure
- 📱 User-focused web interface
